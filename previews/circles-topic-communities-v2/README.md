# Circles: life areas and life stages (prototype v2)

Design work only. No production app code was changed; nothing is committed, pushed or deployed.
v1 is unchanged at `previews/circles-topic-communities/`.

## Open the prototype

    previews/circles-topic-communities-v2/index.html

Open it in any browser (one self-contained file; fonts load from Google Fonts with system fallbacks).
Use the "A · New woman", "B · Returning", "C · Joining later" and "Also" chips to jump to screens, or click through
the phone. Toggle 390 × 844 / 320 × 568 and Default / Larger (130 %) text at the top.
Direct link form: `index.html?scene=b1&dev=320&ts=1.3` (add `&chrome=0` for the phone only, `&full=1` for a full scroll).
