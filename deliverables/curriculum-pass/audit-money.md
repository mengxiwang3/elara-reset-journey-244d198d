# Money Clarity (`money`, MONEY) curriculum audit

Read-only audit of `/home/user/elara-w1` at branch `claude/curriculum-pass` (HEAD `8209939`, "Money Week 1: one connected day"). Nothing in the app repo was changed.

Files read: `tools/curriculum/README.md`, `docs/DAY-STEPS.md`, `docs/GUIDE-VOICE.md` (voice chat only, nothing on path copy), `docs/SAFETY.md`, `apps/mobile/src/content/pathDays/money.ts`, `apps/mobile/src/i18n/locales/{es,en}/pathCopy/money.ts`, the 35 MONEY rows of `tools/curriculum/curriculum-210.json`, the five money rows of `weeks-30.json`, `apps/mobile/src/content/pathCurriculum.test.ts`, `apps/mobile/src/content/moneyDayThreeSlice.test.ts`, `teachingReply` / `authoredReply` / `prefillFor` in `packages/shared/src/practice.ts`, and the reply branch in `apps/api/src/routes/me.ts`.

Three mechanics that shape every finding below:

1. **What she sees after an answer.** Order of precedence (from `me.ts` and `app/path/day.tsx`): an option's authored `replies` line, then an authored `teach` template, then a live model reply, then the step's `elara` floor line. Only Day 3 has `teach`; no Money step has `replies`. So on 68 of 70 steps the feedback is an unauthored model reply when online, and otherwise one of six rotating floor lines assigned by `(day - 1) % 3` in `build.mjs`.
2. **The floor lines** (referred to by code in the table). Ask: **A1** «Gracias. Con eso basta para trabajar.» / **A2** «Eso ayuda. Puedes cambiarlo cuando quieras.» / **A3** «Anotado. Nada de esto tiene que ser perfecto.» Take: **T1** «Es tuyo para conservar, cambiar o dejar.» / **T2** «Algo pequeño y claro es suficiente. Se queda contigo.» / **T3** «Sea lo que sea que escribiste, puedes volver a ello.» All six are `placeholder`: none says anything about the day.
3. **What the test pins.** `pathCurriculum.test.ts` requires `take.body` to equal the document unless the day is in `REWRITTEN_TAKEAWAYS`, and a rewritten takeaway may quote only `{ask}` / `{ask|lower}`. `ask.body` is not pinned (Day 4 already changed it). `teach` cannot reference another day. So cross-day recall can only go in `ask.body` (+ `bodyFallback`) or in a `prefill`; any takeaway rewording proposed below means adding the day to `REWRITTEN_TAKEAWAYS` and is `rewritten-pending`.
