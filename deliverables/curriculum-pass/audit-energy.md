How to read the proposals:

- A script compared every ES and EN question, option list and takeaway to the document: all 35 days match word for word. No ENERGY id is in `REWRITTEN_TAKEAWAYS` and there is no BORRADOR/DRAFT marker in the energy copy (the word "Borrador:" on day 17 is the document's own label for a sample phrase).
- The test pins `ask.title`, the options and `take.body` to the document. It does not pin `ask.body`, `eyebrow`, `sublines`, `placeholder(s)`, `prefill`, `teach` or `replies`. So almost every fix below is additive and keeps the document's question and takeaway. Where a takeaway itself would change, the row says "needs REWRITTEN_TAKEAWAYS".
- Template syntax follows Money day 3 and 4: `{ask}`, `{ask#1}`, `{d15.ask}`, with `bodyFallback`. `teach` can quote the same day only. Every quoting line below has a no-quote fallback.
- Not verified, flagged where used: whether `replies` renders on a `choose` step (the code comment says "for the kinds that carry one inline"; if it does not, use one `teach` template with `{ask}`), and whether `prefill` works on an `ask` reflect step (Money only uses it on `take`).
